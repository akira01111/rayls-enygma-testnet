# testnet-journeys

Step-by-step records of full user journeys on the Enygma Public Testnet —
for example registration, faucet, shielding, shielded transfer, and
unshielding, in the order they were actually done.

Each journey records the sequence of steps, what the interface showed, the
transaction hashes produced, and what was observed at each step. A journey
is only written after it has actually been run.
